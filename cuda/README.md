# CUDA phases

CUDA is deferred until the Phase 1 CPU scenario engine and the Phase 2 CPU LSM
reference are validated. Planned translation units are:

- `gpu_paths.cu`
- `gpu_payoff.cu`
- `gpu_basis.cu`
- `gpu_exercise.cu`
- `gpu_regression.cu`

They are intentionally absent from the initial CMake target.
